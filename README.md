<h2 align="center">🏗️ SECTION 02.5 — SYSTEM ARCHITECTURE</h2>

<p align="center"><sub>TYPICAL BACKEND BLUEPRINT // HOW THE SYSTEMS ARE BUILT</sub></p>

<div align="center">

```
                         ┌───────────────────────────┐
                         │        CLIENT LAYER        │
                         │  (Web / Mobile / 3rd party) │
                         └──────────────┬──────────────┘
                                        │  HTTPS
                                        ▼
                         ┌───────────────────────────┐
                         │        API GATEWAY          │
                         │   Django REST / FastAPI     │
                         └──────────────┬──────────────┘
                          ┌─────────────┼─────────────┐
                          ▼             ▼             ▼
                 ┌───────────────┐ ┌───────────┐ ┌───────────────┐
                 │  AUTH SERVICE  │ │ CORE APP  │ │  TASK WORKERS  │
                 │ JWT / Sessions │ │ Business  │ │  Celery-ready  │
                 │                │ │  Logic    │ │                │
                 └───────┬────────┘ └─────┬─────┘ └───────┬────────┘
                          │                │               │
                          ▼                ▼               ▼
                 ┌────────────────────────────────────────────────┐
                 │                   DATA LAYER                    │
                 │  PostgreSQL (source of truth) + Redis (cache)    │
                 └────────────────────────┬───────────────────────┘
                                          ▼
                         ┌───────────────────────────┐
                         │     DOCKER / DEPLOYMENT     │
                         │  Reproducible environments  │
                         └───────────────────────────┘
```

</div>

<br/>

<div align="center">

| PRINCIPLE | DESCRIPTION |
|:--|:--|
| **Separation of concerns** | Auth, business logic, and background work stay decoupled |
| **Cache-first reads** | Redis absorbs read pressure before it reaches PostgreSQL |
| **Stateless services** | Any service instance can be replaced without data loss |
| **Container parity** | Local, staging, and production run the same Docker image |
| **API-first design** | Every feature is built as a contract before it's built as code |

</div>
